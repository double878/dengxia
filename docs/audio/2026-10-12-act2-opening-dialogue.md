# 第二关第一幕《法海劝酒》自然对白

用户确认六句台词、正常对白与收尾约 30 秒、操作等待另计。最新调度为法海独自走出柳树 → 树旁说首句 → 许仙出门迎接后回话 → 继续交锋 → 许仙真实上前应允 → 自动暗场。

## 台词与来源

| 角色 | 台词 |
| --- | --- |
| 法海 | 许施主，贫僧查明，你家娘子是蛇妖所化。 |
| 许仙 | 我娘子心地善良，怎会是妖？ |
| 法海 | 人妖有别，莫被她的温情蒙蔽。 |
| 许仙 | 大师这样说，可有凭据？ |
| 法海 | 端午将至，你劝她喝杯雄黄酒。是人是妖，一试便知。 |
| 许仙 | 这……我便劝她一杯。若是无事，还请大师莫再疑她。 |

依据已读取的 [京剧《白蛇传》剧本](https://scripts.xikao.com/play/06000050)，并以 [国家京剧院剧情介绍](https://www.cnpoc.cn/cnpoc/gjkt/200902/5113cf6cbea24163ab4e0bd84e7f487f.shtml)、[中央美术学院美术馆皮影故事](https://artsandculture.google.com/story/CgVhg_73SS0vJA?hl=zh-CN)交叉核对。原剧有唱段，许仙此处未直接应允；本项目改为全对白并补写明确应允句，不声称复刻电视剧原话。

## 声音制作

复用已有离线 F5-TTS 与 Seed-VC：32 步/CFG 2.0 生成自然说话内容，25 步/CFG 0.7、长度 1.0、关闭 F0 条件与变调进行角色转换。自然韵律参考仍为《白蛇影》已选原句“人世间竟有如此美丽的湖山”。

许仙身份沿用第一关认可的 `xuxian-answer-continuous-vocals-01.wav`。法海采用 F5-TTS 1.1.22 自带 `basic_ref_zh.wav` 的独立男声身份参考；这是新角色声音，没有已有用户听验认可，不能称复刻某位法海演员。六句新词的听感也没有经用户逐句确认。

制作目录 `builds/act2-dialogue/` 保留请求、原始 F5 输出、Seed 转换、模型哈希核对与技术核验记录。模型及依赖继续使用现有缓存，无新游戏运行依赖。正式资源位于 `assets/audio/act2-opening/`，音源清单 `score.json` 记录实际帧数派生时标、种子、引用哈希、参数及听验范围。

## 动作和时间契约

- 数字键只上场，空格接手；开场提示先按 1 请法海上场，许仙首句结束前不能按 2 提前出现。
- 法海从树后向左走出，解除遮挡并朝门洞方向后就在树旁说第一句。开场站位标记在柳树左侧，不再要求法海走到门前；当前构图的图形验证只走了 380 px，旧面对面开口位置需走约 1,035 px。
- 首句完整结束后在 5,334 ms 静音内冻结主轨，提示按 2 请许仙在门洞中央完整上场、空格接手，从门洞朝法海走近。许仙真实移步至少 40 px、两人相距 220–380 px、面对面且脚点相近后，才播放第二句回话；不将单纯上场视为迎接。
- 第二至第五句连续播放，抬手身段自由；第五句结束后的保护静音内冻结主轨，提示接手许仙朝法海上前一步。
- 只认可提示后许仙实际向法海前进至少 40 px 且面向法海；站位变化由现有控制器完成，不自动代演。等待无超时，方向错误继续等待。
- 自由走位导致重叠或法海换到另一侧时，重新提示上前方向并重记许仙的起点；只移动法海不能解锁应允，舞台边缘也可由重新站位恢复。
- 误退场冻结音频与歌曲时间，再上场保留位置姿态并原位续播；菜单暂停冻结唯一 MusicClock 的双时钟及主播放器。
- 末句完整结束后按歌曲时间进行两秒暗场，清场并显示“端阳”过渡；第二幕饮酒、变蛇、整关计分与录放不属于本次交付。

## 初版验证记录

新行为测试首先以“缺少第一幕对白与应允流程”失败；最终新增流程、宿主与正式回归脚本的解析、gdformat/gdlint 通过。20 个缓存模型及配置文件的 SHA-256 与固定记录一致。七条交付 WAV 完整解码通过，均为 48 kHz 双声道 PCM16，无 NaN/Inf、整数削波或裁头尾；只做固定 0.8 增益，不变速、变调或加混响。主轨实际 1,483,956 帧，时长 30.91575 秒，清单取整为 30,916 ms；22,454 ms 等待应允，28,916 ms 开始两秒暗场。

逐句自动转写覆盖六句，但有“贫僧/平僧”“雄黄/熊黄”等同音差异。许仙末句开头的犹豫音节和“劝她”读音存在转写歧义，原 F5 输出与转换后音源都已单独核对转写；没有据此裁字或反复试种子。转写仅用于定位疑点，新法海音色是否符合低沉中老年听感、所有新词自然度及末句开头仍需人耳试听。

## 首句与迎接调度修订验证

本轮只改动作许可、提示、站位标记和 JSON 的 `greeting_gate_ms`。七条 WAV 当前 SHA-256 全部与交付清单相符，台词、音色和 30,916 ms 主轨时长沿用；首句后的 350 ms 静音容纳 5,334 ms 冻结点，距许仙字头保留 230 ms。

更新后的对白测试先在旧实现上因“首句结束前许仙提前出门”“法海走出树旁后没有独自说首句”失败；实现后 36 项全部通过，包含首句误退场续播、许仙上场许可、迎接等待无超时、错误方向/朝向及法海缺席时不回话、后续应允与暗场。入口与开场操演各 28 / 109 项通过。逐文件解析、gdformat/gdlint 通过。

Windows/OpenGL/WASAPI 实演 22 项、0 失败，实测法海走 380 px 后独自开口；首句后的播放器停在 5,368 ms，早于许仙字头 5,564 ms，等待期间歌曲时间和音轨均冻结。许仙实际从门洞走近后显示并播放第二句，法海保持树旁原位，最终暗场清场；全程墙钟 33.309 秒。图形日志无音频停摆或脚本错误，截图与报告在 `builds/act2-greeting/`；临时探针及 UID 已删除。

`tools/run_godot.ps1` 新日志前缀 `act2-greeting-*`：A 整套 1,284 + 22、B 视觉 379、C 整套 459 条断言通过。资源导入、60 帧无头启动、Windows release 导出均退出 0；导出主入口启动及同版本编辑器从 PCK 单独加载第二关也均退出 0，新的迎接时标清单可加载。无头快速退出仍有前述既有资源释放提示，声音的人耳听验范围沿用初版记录。
