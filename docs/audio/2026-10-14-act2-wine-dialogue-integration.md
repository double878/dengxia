# 第二关对白、劝酒对唱与视频音乐

2026-10-14。用户要求正式生成并接入，不再使用临时字幕排练。沿用第一关既有角色音色。新声音已通过技术与实际游戏播放验证，尚未由用户逐句听验。

## 交付行为

法海实际上场时循环播放用户视频中的 8.256 秒音乐；走出树、面向门洞后开口，先停音乐再播放已有法海对白。只在初次出场等待期间配乐，对话中误退再上场不重播。

厅堂先播放五句普通对白：许仙劝酒、小青劝阻、许仙请小青买酒菜、白素贞「小青，你就去吧」、小青「好吧」。最后一句完整结束后等待小青实际左侧退场，然后播放约 41 秒连续对唱：

| 角色 | 唱词 |
| --- | --- |
| 许仙 | 端阳佳节共举杯，愿与娘子长相随。 |
| 白素贞 | 官人盛意心领会，只怕薄酒也难支。 |
| 许仙 | 只此一杯添欢喜，娘子莫再把杯推。 |
| 白素贞 | 既是官人再三劝，且饮一杯谢情意。 |

唱完全部尾腔后才开放取杯、递杯和实际饮酒。饮后实际 Alt 拖腰到位，才播放白素贞「官人，我身子有些不适」，随后许仙「娘子稍候，我去取些药来」；两句使用普通说话语调，没有持续背景音乐。原压灯、换蛇、取药返回与惊倒动作保持。仰倒进度达到 0.95、身体落地时，播放一次视频重音；暂停冻结全部声音与双时钟。

## 来源与制作

- 剧情参考：[戏考《白蛇传》](https://scripts.xikao.com/play/06000050)，酒变段「再三劝我饮酒浆」「又恐怕夫妻的情义伤」；原段以白素贞演唱和许仙对白为主，本项目的两人对唱和新词属于游戏改编。
- 核对场次：[CCTV《白蛇传·酒变》2020](https://tv.cctv.com/2020/05/30/VIDEQhTPePt0Wtwedg6yZ0oO200530.shtml)、[CCTV《白蛇传》第四场酒变 2023](https://tv.cctv.com/2023/08/12/VIDEAyXWmJ42JQwFOErcSxPB230812.shtml)。页面与部分视频参考缓存在 `.firecrawl/` 和制作目录，未把失败的整片下载作为证据。
- 实际旋律/伴奏来自第一关采用的 [CCTV《白蛇传》游湖](https://tv.cctv.com/2020/07/02/VIDEGhi9Sw6SpdWEg573OBfO200702.shtml)，原片 837–879 秒连续窗口。酒变资料用于情节和劝酒情绪；不能将生成段宣称为原版《酒变》唱腔或已测定的板式/BPM。
- MelBandRoformer 分离一次连续人声与伴奏。四个连续窗口生成新词，角色身份分别来自原 pilot 的纯人声与准确原词。YingMusic 32 步、CFG 3、t_shift 0.5、句级对齐、尾部 0.5；种子 2026101401–04。伴奏只截一次、角色之间不拼伴奏，保留全部生成采样；第三组末尾跨下一窗口约 2 ms，未裁掉尾音。
- 自然对白用 F5-TTS 32 步、CFG 2，再用 Seed-VC 25 步、CFG 0.7、长度 1.0 匹配各自角色；关闭 F0、变调、混响。七句种子 2026101300–06，韵律/身份参考取工程实际交付的第一关普通对白。CPU float32，每模型 8 线程。
- F5/Seed 20 份缓存文件和歌唱/分离 4 份权重/配置重新核验完整 SHA256；歌唱源码 revision `baa409c2e7e5e775f09b4e92a220808f4827d2cc`，权重 revision `7443a818cb43c5ece9976a78ec8b625660bc522d`。请求、参数、参考与成品哈希在音源清单及 `builds/act2-hall-audio/` 制作记录。
- 用户音乐来自 `20261013-1538-24.6072238.mp4`。原音频 48k 双声道，出场曲固定增益 0.65、两端各 45 ms 淡变；重音选原音频 6.435–7.735 秒，3 ms 起点/60 ms 尾部淡变。原视频 SHA256 和音源 SHA256 保存在清单。没有声称已由人耳确认重音选段。
- 对白与对唱仅重采样、固定增益，实测约 −18 LUFS，无强制变速/变调/裁头尾。交付 11 条 WAV，48k 双声道 PCM16，导入禁用裁剪、归一化、循环和有损压缩。

## 调度与核验

`assets/audio/act2-hall/score.json` 是波形派生时间表；主轨 69,517 ms，小青离场冻结点 19,419 ms，对唱 20,119–61,119 ms，饮酒/弯腰等待冻结点 61,269 ms，取药离场冻结点 68,517 ms。三处等待后至少 700 ms 静音保护。主轨不循环，真实动作才允许前向跳到下一段；不重置真实时间。惊倒时保持主轨冻结，以真实时间推进姿态。

实际验证使用 `D:\Godot\4.7.2\godot.exe`，同版本模板，包装入口 `tools/run_godot.ps1`：
