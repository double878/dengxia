# 开篇引入方式横向对比分析

> 素材：两段 B 站录屏（2026-10-06，Panky 提供）。  
> 方法：逐帧拆解（每 8 s 一帧）+ 音频静音检测（判断旁白分布）。  
> 范围限定（按 Panky 要求）：**忽略人物、剧情、美术风格**，只看「开篇呈现形式」与「介绍信息的组织方式」。

| 编号 | 作品                             | 素材性质                    | 总长       |
| -- | ------------------------------ | ----------------------- | -------- |
| V1 | 《物鹿山河 · 天工解密》（2D 物理解谜，同赛道参赛作品） | 团队介绍视频：游戏画面 + 底部解说字幕    | 1:34     |
| V2 | 《九章奇旅记》（九章算术题材，同赛道参赛作品）        | 实机录屏（从启动开始），B 站完整版 4:47 | 1:45（截取） |

## 1. V1《物鹿山河》：结构拆解

| 时间      | 形式                                                                            | 传达的信息                                                | 交互性           |
| ------- | ----------------------------------------------------------------------------- | ---------------------------------------------------- | ------------- |
| 0–16 s  | 标题页：主视觉 + **竖排「按任意键开始游戏」**                                                    | 游戏定位一句话（解说：「2D 物理解谜游戏」）                              | 高（第一屏就是交互入口）  |
| 16–36 s | **漫画分镜开场动画**：约 10 格黑白分镜依次呈现，底部旁白字幕                                            | 世界观 + 任务目标。**一格一个信息点**：危机 → 主角决定 → 行动纲领（收集遗物/修复时间绷带） | 低（线性播放）       |
| 36–56 s | **大地图 = 主菜单**：地图节点即关卡；左侧竖排图标栏（设置 / 人物 / 图鉴 / 退出）；点人物 → **卷轴式人物介绍**（立绘 + 竖排文字） | 游戏结构（有几关、去哪玩）+ 可收集要素（图鉴在一级入口）                        | 高（所有介绍内容都可点开） |
| 56–72 s | 进关卡：对话框剧情 → **科普卷轴**（「指南针」主题，竖排图文 + 继续按钮）                                     | 本关要学的知识**前置**，先给知识卡再进玩法                              | 中             |
| 72–94 s | 实机解谜演示 + 解说顺带报技术栈（Unity）                                                      | 玩法与手感、专注感                                            | —             |

**信息组织顺序**（解说字幕的顺序）：类型定位 → 世界观 → 游戏结构 → 知识/教学 → 实机与技术。这个顺序基本就是评委/玩家关心一个陌生游戏的顺序。

## 2. V2《九章奇旅记》：结构拆解

| 时间      | 形式                                                                                                                        | 传达的信息                             | 交互性    |
| ------- | ------------------------------------------------------------------------------------------------------------------------- | --------------------------------- | ------ |
| 0–5 s   | 黑屏起步                                                                                                                      | —                                 | 无      |
| 5–44 s  | **开场动画（约 40 s）**：单物件聚焦（钥匙特写）→ 物证链（结绳记事 → 算筹 → 竹简）→ 主题物《九章算术》**居中** → 玩法维度物件**环绕书旋转**（几何/体积/方程/度量/方田）→ 收束。**右上「>>跳过」全程常驻** | 纯视觉讲完「数学史 + 游戏内容维度」，**不出现一句说明文字** | 低（仅跳过） |
| 56–64 s | 剧情对话（动机：书太难）→ **白屏转场**                                                                                                    | 动机                                | 中      |
| 64–88 s | **村庄主界面**：左侧竖排图标栏（设置 / 人物 / 藏书）+ 右上返回 + 右下分享；设置面板 = 卷轴音量条；人物面板 = 画框头像 + 卷轴简介；**藏书面板 = 书架，每本书是一个章节**                       | 游戏结构：**书 = 章节，架上的书就是内容目录**        | 高      |
| 88–96 s | 点书 → **卷轴关卡页**：题目名（分田法）+ **初级 / 高级两块难度牌**                                                                                 | 章节内的关卡与难度                         | 高      |
| 96 s+   | 进关卡 → 剧情 → 玩法                                                                                                             | —                                 | —      |

**信息组织的两个高招**：

1. **主题物居中 + 内容维度环绕**：开场动画最后一张图，同时回答了"主题是什么（九章算术）"和"内容有哪些块（几个数学概念）"。一张图说完整个游戏的内容结构。
2. **进度即实物**：未解锁的章节 = **被锁链锁住的书**；人物面板里未解锁的角色 = 黑影 + 问号。玩家不看菜单也知道"还有什么没玩到"。

## 3. 横向对比（只比形式与信息组织）

| 维度        | V1 物鹿山河               | V2 九章奇旅记                    |
| --------- | --------------------- | --------------------------- |
| 第一屏       | 标题页 + 「按任意键」（先给交互）    | 黑屏 → 动画（先给氛围）               |
| 开场动画形式    | **漫画分镜**：多格并置，一格一信息   | **物证链**：单物聚焦 → 链条推进 → 主题物收束 |
| 开场时长      | 约 20 s                | 约 40 s（可跳过）                 |
| 世界观传达     | 旁白 + 文字分镜             | 纯视觉，零文字                     |
| 主菜单形态     | 大地图（关卡 = 地图节点）        | 村庄场景（章节 = 书架上的书）            |
| 功能入口      | 左侧竖排栏：设置/人物/**图鉴**/退出 | 左侧竖排栏：设置/人物/**藏书**          |
| 「介绍内容」的载体 | 卷轴面板（人物介绍、科普卡）        | 游戏内实物（书、卷轴、难度牌）             |
| 进度可视化     | 地图节点推进                | **锁链锁书 + 黑影 + 问号**          |
| 转场        | （介绍片剪辑，无参考价值）         | **白屏硬转**（连续性断裂）             |
| 明显短板      | 开场动画偏低幼、与后实机画风断层      | 前 5 s 黑屏、40 s 无交互动画、白屏转场    |

## 4. 两家共用的范式（赛品类开篇的隐形标准）

1. **介绍内容全部"藏进游戏里"**：人物介绍、知识科普、章节目录都不放片头字幕，而是做成游戏内可点开的东西（卷轴 / 书 / 图鉴）。片头只负责"想不想玩"，不负责"是什么"。
2. **场景即菜单**：主界面不是按钮列表，是世界本身（地图 / 村庄）。功能入口做成场景里的实物。
3. **一个主题物当锚**：V1 是神鹿，V2 是《九章算术》这本书。开场的落点永远是一件具体的、能反复出现的道具。
4. **中式竖排侧栏**：两家都用左侧竖排图标栏承载功能入口，古风、省空间、不抢画面中心。
5. **知识 / 教学包装成收藏物**：科普做成卷轴卡，先于玩法给出，有"收集感"。

## 5. 《灯下》的应用方案

### 5.1 开篇样式（吸收 + 规避）

| 借鉴点              | 来自         | 《灯下》的落地                                                                                                                          |
| ---------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **标题页与第一场合一**    | V1 的「按任意键」 | 标题页不做独立界面：**待机画面就是第一场「灯下修影」的静帧**（爷爷补影人），标题「灯下」+ 副题「一盏灯，照六个人」浮出，右下竖排「按任意键 · 点灯入戏」。按键 → 灯亮 → 第一场开始。**零黑屏原则不破**，同时拿到 V1"第一屏即可交互"的优点 |
| **主题物居中 + 维度环绕** | V2 动画收束帧   | 第七场标题浮出帧：**木箱打开，六个头一字排开（或一挂影窗六格）**——一张图同时说清"六个头 = 六个人的命 = 六关"。这就是 V2 那张"书 + 环绕物件"的皮影版                                            |
| **「>>跳过」常驻**     | V2         | 配合 8.1#2 的"跳过浓缩版"：开场右上皮影体「>>跳过」，点击进 20 s 浓缩交接（保留覆手）。V2 的教训同时吸收：**跳过按钮有，但白屏转场没有**                                                 |
| **漫画分镜开场**       | V1         | **不采用**——但它的用法可迁移：分镜感留给 B 站**介绍视频**（见 5.2），游戏内开篇仍用实机灯下演法（连续、可操作）                                                                 |
| **规避白屏硬转**       | V2 反面      | 零黑屏原则再次确认：转场只靠"构图相同 + 灯光变化"，绝不整屏填充色切换                                                                                            |
| **场景即菜单**        | 两家         | **关卡选择不做菜单列表**：用「影窗」或「戏箱」——六个头摆在箱里/影窗六格，点一个头 = 进一关                                                                               |
| **中式竖排侧栏**       | 两家         | 左侧竖排栏，皮影语义化命名：**戏箱（设置）/ 影人谱（人物图鉴）/ 戏折子（剧目与教学）**                                                                                  |
| **进度即实物**        | V2 锁链      | **未回收的头 = 蓝布包着**（F2 伏笔现成）。进度可视化 = 蓝布逐个揭开——比锁链更贴主题，且伏笔自带回收                                                                        |
| **难度牌**          | V2 初级/高级   | 选关页用**戏班水牌**（戏园子贴的"今日戏码"牌），难度写在水牌上                                                                                               |
| **知识卡前置**        | V1 科普卷轴    | 第一关进关前给一张**戏折子**：本关剧目《断桥借伞》+ 一句目标（借了就得还）。只此一张，不做成常驻系统                                                                            |

### 5.2 游戏介绍（参赛/B 站视频）的信息组织

学 V1 的解说顺序，套到《灯下》：

| 段 | 内容                                  | 对应画面                      |
| - | ----------------------------------- | ------------------------- |
| 1 | 类型定位一句话                             | 标题帧 + 灯下修影静帧              |
| 2 | 核心体验（**操作皮影**，不是光影解谜）               | 爷爷一人操三影 + 手部特写            |
| 3 | 结构（五关 + 六个头）                        | 影窗六格 / 木箱                 |
| 4 | 玩法与判定（操影 + 换头，唱腔不参与判定）              | 实机 + 一句艺训字幕               |
| 5 | 技术与特色（Godot 4 / 自研 shader / 皮影贴图规格） | 分镜感的多格并置（这里才用 V1 的漫画分镜手法） |

**要点**：介绍视频里"技术栈"放最后一笔带过（V1 的做法），不进游戏本体。

### 5.3 与既有设计的冲突检查

- 标题页合一：与「第七场末帧 = 第一关首帧」不冲突——标题页是**开机待机态**，在第一场之前，同一场景不同灯光态。
- 影窗选关：第一关之后才出现；开篇七场内不出现任何选关 UI。
- 蓝布揭头：与 F2（父亲的头）并线——最后一个揭开的必然是蓝布最厚的那一个。
