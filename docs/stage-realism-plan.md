# 《灯下》皮影舞台实物质感升级：调研与实施方案

日期：2026-10-08。状态：已按确认方案实施视觉升级；验证与导出程序限制见 [交付记录](stage-realism-delivery.md)。

## 1. 目标与已确认选择

让玩家能看出自己在一座真实小影戏台的幕后：绷紧的透光棉布、带接合与磨损的木架、皮影实体及其操作签、小油灯和幕上透色影像。材质与投影共同产生实物感，光晕和颗粒保持克制。

| 决策 | 用户选择 | 对方案的约束 |
| --- | --- | --- |
| Q1 观感 | A，实物感为主 | 棉布、木框、竹签、小油灯；轻光晕、轻颗粒。 |
| Q2 投影层次 | A，区分实体与投影 | 保留现有滚轮、Q/E、动作判定及状态字段；显示层区分实体、操作签和投影。 |
| Q3 构图 | A，保留当前画幅与操作区 | 保留约 3:1 幕布，以及灯、手、挂钩、头架的交互位置；结构细节在既有布局内补足。 |
| Q4 幕前验收 | A，幕前渲染与开发验收场景 | 本轮制作幕前渲染和独立开发验收场景；正式回放接入后再核对实际记录。 |

沿用 PRD 的固定幕后演出与关后幕前揭示。此次升级使用现有角色和动作，视图只消费状态，不反向修改操控、判定、灯油或道具归属。

## 3. 真实舞台的细节及对画面的影响

### 3.1 幕布：薄、透光、散射、绷紧

- **材料：**布幕与纸幕都有来源。S2 确认半透明布幕，S3 描述白棉纸/白布，S5 描述白棉布绷框。游戏采用用户已确认的暖白棉布，不宣称所有华州历史戏台都使用棉布。
- **透光：**幕布让背光和影像到达观众，同时遮住幕后空间。半透明应表现为漫透射、柔和亮度与织纹，而非玻璃式看穿后台。纹理密度、厚薄和散射共同影响观感；屏幕 alpha 并不等于真实透光率。
- **尺寸：**S1 的通用影窗描述为高 3 尺、宽 5 尺，最大尺寸描述为高不过 4 尺、宽不过 6 尺；S3 给出另一种 3×7 英尺实例。两者单位及适用范围不同，不混成一个标准，也不把古代“尺”直接按现代单位精确换算。本轮保留现有 1788×588 设计像素幕面，约 3.04:1，作为游戏构图取舍。
- **绷紧：**投影区域平整，边缘能够承受轻接触；框周有布边和拉紧点。S5 提到扣眼绷框；游戏以包边、绳结与有限拉痕表达可调张力，这是可解释的结构设计，不是考证到的华州固定绑法。
- **皱褶：**细小拉痕集中在边角，中央平整。整面厚褶、持续飘动会破坏清晰投影及接幕表演的感觉。

### 3.2 油灯：小型有限光源，照亮幕面

- S1 记载油灯一盏；S3 另述多灯蕊油灯及后来的汽灯、电灯。灯具和发光范围随演出形式变化。本轮采用已选定的小单灯版本。
- 发光体是灯芯上方有面积、有高度的火焰，不能当成整只灯碗发光，也不画舞台追光式的锥形光柱。长形火焰会带来略有方向差异的半影，这是光学推导。
- 暖黄光是项目方向。拟从 **1800–2200 K 的暖色观感**试样开始；该范围是美术参考，不是油灯实测温度或火焰燃烧温度。幕布和角色需保留染色差异，不能把所有物件统一染成橙色。
- 稳态火焰也可有轻微的不规则形变；气流、灯芯和燃烧条件影响它。没有可靠统一闪烁频率；游戏采用缓慢起伏叠加细小快变化，保持形变、亮度和光晕有所关联，但不完全同幅。
- **灯距：**可靠资料支持“灯、影人、幕的位置要共同安排”，未支持一个通用厘米数。灯在影人之后照向幕，影人接近幕；操作者的手和杆通过灯位与遮挡尽量减少露影。本轮灯在手边矮处的位置沿用现有布局，这是游戏构图，不声称所有戏台都如此布灯。

### 3.3 工作台、连杆和支撑

- 华县现场记述支持简易木桌与木板搭台；后台首先是能装拆、能放道具、能操作的工作位置，木材有厚度和接合。[S4]
- 影人头、躯干及四肢分件连接，主要控制为胸/身部一签、两手各一签。[S1] 控制杆的移动通过关节把动作传给手臂和身体，不是三根与影人无关的装饰线。
- 游戏竹签表现细长、稍有纤维与节痕，连接处有系结/小接件；皮影关节和紧固件沿用现有角色资产。不同制作习惯的线缀、铆接等不统一标成某一种历史规范。
- 胸签承担平移、提起、落下和翻面的主控制；手签抬落两手，经前臂与上臂的铰接形成举手、持物等动作。身体的起伏、手势和有限的下肢被动运动组合成步行、施礼等表演。保持现有分件动画，不增加全身物理模拟。
- 框后补充立柱、横档、接合与少量支撑；工作台补充木板拼缝、前沿厚度和局部物件遮挡。头架及挂钩是现有游戏操作设施，其数量和排布不包装成传统戏台标准。

### 3.4 影人怎样产生彩色投影与运动

空间顺序为：**灯 → 影人 → 幕布 → 观众**。操作者位于后台操作签杆，身体无需处在主投影光路内。

透光皮革上彩后，光经过皮革和颜料形成有色影像；镂空处更亮，厚皮、重色线和重叠部分更暗。[S1、S2] 影人靠幕时轮廓清楚；离幕后，有限光源产生更宽半影，投影也可能变大、变虚。[S5、S6]

用平行幕面上的简化模型说明趋势：设灯到影人距离为 `s`，影人到幕为 `h`，光源横向尺寸为 `a`，则投影放大约为 `M = 1 + h/s`，半影宽度约为 `w = a·h/s`。倾斜影人还会发生压缩与形变；这些关系用来指导表现，不直接重写玩法。

示例输入 `h=2 cm`、`a=1 cm`、`s=80/50/30 cm` 时，放大约 `1.025/1.040/1.067`，半影约 `0.25/0.40/0.67 mm`，灯到幕相应为 `82/52/32 cm`。**这是演示公式的任意示例，全部不是传统实物测量值。**它说明贴幕表演本来可以很清晰，游戏现有明显缩放是为可读性放大的操控反馈。

灯影随移动、翻面、关节转动和透色变化产生运动；合理的变形应跟随灯与姿态。随机关节乱抖、持续大斜切、两盏灯式双重影子不符合本轮方向。杆影通过灯位与遮挡尽量减弱，少量露影可以存在，不把幕前绘成密集竹签网。[S3、S5]

## 5. 推荐的视觉方案

候选路径：①在现有单层画面增加纹理与滤镜，成本低，但实体与投影仍混在一起；②**保留 2D 状态驱动，区分实体与投影，并使用轻量幕面材质**，能解决本次主要问题，推荐采用；③改用 3D 与完整物理投射，成本和回归面大，与现有技术设计及用户 Q2 选择不符。

### 5.1 棉布透光与半透明质感

以项目暖白 `#EFE8D8` 为受光参考，保留未照亮时的灰暖色。织纹分为细密经纬、少量不均纤维、低频厚薄变化三层；近看有纤维，正常观看不出现粗格子或摩尔纹。中央平整，边缘显示包边、绳结拉痕与轻微积尘。

幕面照度表现连续过渡、局部暖光和轻边缘衰减。纤维调制透射光与投影，让画面附着在布上。幕布半透明不通过降低整块幕的 alpha 来实现；不能让观众透过布看清后台。

**预期：**灯暗时像布，灯亮时像被照透的布，透色影像与纤维属于同一个表面。

### 5.2 光影投射与柔边

投影由完整分件姿态组成，经过统一的缩放、有限偏移与轻斜切后落到幕面。沿用当前灯距反馈的方向与原型范围（现有缩放 0.78–1.36 为基线），实测检查可读性；这些是相对参考倍率，不是实体几何的实测放大率。

默认贴幕时保持锐利轮廓与清楚镂空，只加很窄的布面散射柔边。灯靠近时可轻微加大半影。额外离幕演示只在开发验收场景中用固定样例展示，不添加游戏输入。

投影裁切在既有幕面；边框、手、实体竹签和界面保持清晰。取消脚下“地面椭圆影”，只保留解释得通的幕上透射与后台接触阴影。

**预期：**边缘柔和但细花纹仍可读，变形有一致原因，影像不会浮在布前。

### 5.3 油灯、火光、光晕与闪烁

灯体使用小碗式器皿设计，呈现口沿厚度、暗油面、灯芯、局部油渍、使用痕迹和邻近暖反光。器皿具体形制属于本项目美术选择，不宣称精确复刻某件馆藏。

火焰以柔曲线与亮焰、暖黄区域、橙色边缘和灯芯暗部组成；火焰与周围局部光晕共同变化。用固定种子的连续噪声/多频变化模拟自然起伏；鼓点的轻脉冲与合拍稳定反馈叠加其上，不能使整块幕像节拍灯闪灭。

将 `flame_feedback` 高值映射成更稳定的形状与较小亮度波动，低值增加有限摇曳。`oil` 继续只影响现有的环境变化；`exposure` 控制幕影显露，不能让低显露时实体、签子和手一并消失。

**预期：**火焰有生命感，油灯在物件上留下局部反光，错拍可感知，正常操作舒适。

### 5.4 影人投影变形与层次

实体层展现较暗的皮革背面、紧固件、薄边缘和实际连接；投影层展现染色透皮、镂空亮区与重叠暗部。两层复用同一关节、翻面、换头和持伞状态；实体不因滚轮而改变物件尺寸。

投影使用覆盖/镂空信息与染色透射信息。纸面式透明 PNG 的 alpha 只描述轮廓与孔洞，不能直接当成皮革物理透光率；透色信息可由现有分件另存渲染材料配置或辅助遮罩，保留原图和枢轴。

重叠的染色皮革采用有界透射乘积近似：孔洞接近全透，线刻重色较暗，同一区域多层叠加更暗。按线性颜色空间合成，避免直接叠加 sRGB 导致发灰或过黑。统一进行轻微投影偏移，避免把实体与投影人为分成两具错位角色；幕后贴幕区域由实体合理遮挡，幕前只呈现幕面结果。

伞的实体跟随实体手腕，伞的投影跟随同一投影变换；快速翻面时头、双手、伞同步。保持现有身体与头的固有染色，不能靠整图随机变色模拟材质。

**预期：**白素贞衣饰区别于幕布，小青与许仙仍可辨，镂空透亮，双臂、身体和道具重叠有厚薄层次。

### 5.5 舞台边框与后台结构

在现有幕面外补足木框厚度、内沿暗部、接合、局部磨损与侧后横档；视野边缘只放少量必要支撑。台面增加拼板、刮痕、前沿厚度和油灯/架子的接触暗部。头架、挂钩和抓签位置仍沿用当前操作区域。

竹签一端接胸部与手腕，一端接操作者的握持位置，显示真实杆身、细纤维、小接件；翻面和抬手过程中不能穿错连接点。主幕投影避免大量杆影，有限杆影可在下沿或边框遮挡区域出现。

**预期：**舞台能够被理解为搭起来的结构，后台是可工作的空间，操作位置仍容易辨认。

### 5.6 整体色彩与颗粒氛围

沿用项目暖白、木褐、油灯暖黄和角色固有色。暖色集中在幕面与灯附近，阴影采用较中性的深木褐；保留暖白衣服与幕布之间的轮廓、纹样和亮度区别。

颗粒首先来自静态布纤维、木纹与皮革；动态颗粒仅轻量叠加在幕面/环境，局部少量尘点须在受光范围内。画面有轻暗角和自然明暗，不采用全屏重噪声、强烟雾或镜头光斑作为主要质感来源。界面与操作提示维持清晰。

**预期：**整体古朴而能读清动作，靠材料本身形成氛围。

### 5.7 初始调试参数（全部是设计值）

| 项目 | 起始值/范围 | 校准依据 |
| --- | --- | --- |
| 幕布细纹亮度调制 | 约 1%–3%，静态 | 正常视距可感知布面，不出现大格子或缩窗闪纹。 |

## 6. 2D 实现方法、接口与文件范围

使用现有 Godot 4.7.2 Standard、Compatibility 和内置 2D 能力。先做局部幕面渲染，不引入新的运行时依赖或物理光照系统。

**数据流：**`PuppetState / LampState / UmbrellaState + 既有时钟读数 → 共享分件姿态和投影参数 → 幕后实体层 / 幕面投影层`。开发幕前视图读取同一份样例状态，仅镜像舞台横坐标与正面表现，不另算动作。

建议结构：舞台表现入口负责组合背景、幕面、实体、签杆和道具；共享姿态/坐标辅助负责实体挂点及其投影映射；油灯表现负责灯体与火焰。材质参数只在表现层维护，避免做通用渲染框架。

- 复用现有分件、枢轴、翻面和状态读取能力；原有显示脚本按接口渐进适配。
- 主幕采用一个共享 `SubViewport` 合成影人及伞的透射纹理，再由幕布 `CanvasItem` 材质结合照度、织纹和局部柔边显示。先做一具影人的验证样段，再扩展所有在场及挂起影人。
- 透射纹理采用白色全透背景；孔洞保持全透，染色层以透射乘积近似合成。新辅助纹理/材料不覆盖角色原图，也不变更头与身体的实体归属。
- 优先只柔化投影纹理，采用有限采样；不把整屏先截取再反复模糊。正常幕面优先保持足够分辨率，再由性能证据决定降采样，不能先牺牲镂空纹样。
- 灯体局部光晕使用轻量渐变/材质；不依赖切换渲染器才能工作的全屏 Bloom。
- 实体胸签命中位置沿用控制器坐标；实体挂点与投影挂点分别提供清楚命名的读取接口。旧 `hand_screen_position()` 被伞和测试消费，改动时必须核对调用方，不能让一个含糊接口同时表示两个坐标系。
- 幕布、挂钩和头架保留已选定布局；投影裁切不得裁掉操作手和实体杆。极端站位的自然裁切与玩法范围分别处理，不能静默改 A 的归一化坐标或判定边界。

**时间约定：**自然火光读取现有 `MusicClock.get_real_time_ms()`，节拍反馈读取歌曲时间与鼓点；菜单暂停使两者冻结，补救时真实时间可继续而歌曲时间停止。固定种子与显式 shader 时间使同一状态、同一演出时间得到同一光效。正式回放接入后，视觉真实时间由记录中的冻结事件重建，不能读电脑墙钟或另设自由计时器。这是显示约定，尚不代表 C 已实现。

**预期文件范围（待实施时根据现状精简）：**

| 范围 | 用途 |
| --- | --- |
| `assets/stage/`、`shaders/` | 自制布纹、木纹、灯体、绷布细节、幕面与火光材质；保存可编辑原稿和来源说明。 |
| `scripts/b/`、`scenes/b/` | 轻量舞台/油灯表现，以及已确认的独立开发验收场景。 |
| `scripts/a_test/placeholder_puppet.gd`、`placeholder_lamp.gd`、`level1_a_scene.gd` 与对应场景 | 复用并接入显示能力；只做必要适配，不把整个 A 测试目录重构。 |
| 少量正式视觉契约回归测试 | 坐标/挂点、全场灯影作用、状态只读、反馈方向与视觉时间冻结。 |
| `TECH_DESIGN.md`、必要的 A→B/C 接口说明 | 写入已经确认的层次、坐标和视觉时间约定；避免留下和代码相反的接口描述。 |

不将研究图片或馆藏照片直接打包成游戏素材。现有角色原稿、清单和用户未提交修改先确认再接入；不手工编辑引擎生成的导入缓存。

## 8. 验证、性能与交付

### 8.1 可观察的验收条件

1. 正常视距下幕面能辨认是绷紧的织物，透色影像附着在纤维表面；中央平展，木框和布边有结构。
2. 贴幕默认轮廓清晰，灯距变化的柔边克制，重要镂空与白衣纹样可读；离幕开发样例呈现有依据的变大/变虚趋势。
3. 灯芯、火焰、器皿和局部光晕可区分；正常火光轻微变化，合拍更稳定，低合拍有限摇曳。
4. 实体影人和竹签可操作；降低显露度不会让实体消失，滚轮不会改变实体物件尺寸或命中位置。
5. 胸签/手签连到正确实体挂点，翻面、抬手、换头和伞交接时不漂移；伞与影人使用一致投影变换。
6. 所有在场和挂起影人共享灯影参数，保持姿态与道具归属；重叠透色表现为更暗或综合色，没有贴纸式灰边。
7. 在最低灯况仍能看清手、签、头架、挂钩；白素贞与幕布可分，三人轮廓灰度可辨。
8. 开发幕前画面镜像、染色和投影正确；正式回放的实际记录一致性在接入后单独核验。
9. 固定种子与时间下光效一致，菜单暂停完全冻结；图形实测不凭无头结果替代。
10. 实际 Windows 演示机 1080p 目标稳定 60 FPS；记录连续帧时数据，检查新增光效的耗时、暂停恢复及输入响应。
