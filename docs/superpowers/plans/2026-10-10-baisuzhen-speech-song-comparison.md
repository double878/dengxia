# 白素贞普通对白与唱声音色对照小样

**最新执行范围（2026-10-10）：**用户已经确认第二版“自然、无电音，音色也一致”，并明确要求“别生成小样了，赶紧生成对白接入游戏”。后文的小样边界保留为历史记录，已由本轮指令覆盖。直接制作已批准的四句开场与九句还伞对白，复用通过的六句借伞对唱与器乐，接入第一幕现有宿主。新对白使用 F5-TTS 离线生成内容，再用已通过的 Seed-VC 普通语音配置匹配各角色音色；不再要求逐条试听批准。验证自然对白无背景音乐、唱段完整、真实交接条件、8 秒等待、暂停和正式 Windows 导出；实际幕前回放尚未接线时明确标注。

本轮依据：用户确认 `1A 2A 3A 4A`、`5A 6A`。已授权制作一个白素贞短小样，听验后再扩展角色；不重复请求开始制作许可。

## 目标、边界与验收

- 每个角色保留自己的音色；白素贞普通对白匹配已通过唱声。
- 有持续伴奏的台词演唱，无持续伴奏的台词自然说话，不使用京剧念白或拖腔；环境音和单次收锣不算伴奏。
- 整句/段落的表达方式由编排决定，短暂停顿、淡出和用户静音不改变方式。
- 保留已通过京剧唱段原文件；仅制作“普通对白 → 原唱段 → 普通对白”候选。两个对白取已批准台词，不新增剧情。
- 最终听验由用户确认：对白自然、词句完整、没有电音；前后对白与唱段听出同一白素贞音色。文件解析通过不等于该听验通过。

## 有界制作步骤

1. 输入核验：读取现有 `builds/act1-jingju-pilot/generation-result.json`，要求 `accepted_by_user`；复核纯人声与带伴奏唱段的 SHA-256。输出为请求中的冻结音源元数据，变化则停止。
2. 普通语调参考：使用已安装 `Microsoft Huihui Desktop`，按已批准两句台词离线生成两个无音乐参考。此工具声音仅作为语调条件，不作为对白成品。输出为参考 WAV 和实际工具信息；完整解码、非空和有限数值必须通过。
3. 两句对白生成：复用现有 CPU YingMusic-Singer-Plus 及权重，已通过白素贞纯唱声作为同一音色条件，普通话参考作为各句语调条件。最多两次模型调用，单进程限时 300 秒；不变速、变调或加混响，不改作者源码。普通说话是本轮能力实验，尚不能由歌唱模型名称或参数证明。
4. 编排与复核：48 kHz / 16-bit PCM；完整保留两个对白及原带伴奏唱段，句间 500 ms 静音。另出无伴奏的人声对照版。独立读取和严格解码所有输入/输出，检查哈希、削波、时长、段落逐采样一致和停顿为零；听验状态保持 `pending`。

## 参考更新后的单句实验

用户确认旧对白不自然且有电音，原唱声满意；原 Huihui 参考没有电音但不自然。用户随后提供《白蛇影》并授权“都可以的，你自己挑选一句”。原方法及判退记录保留，停止用该歌唱配置生成对白。

本次验证一个假设：由真人普通对白提供内容与节奏，使用专用普通语音音色转换匹配已通过唱声，可以绕开旧机器语调输入与歌唱生成入口两处不适配；最终是否自然、无电音和同音色只能由新小样听验决定。此实验沿用所选参考句原词，专门测试说话自然度和唱说音色衔接，不宣称已经替换游戏台词。

1. 复核已取得《白蛇影》音视频哈希，选择游湖场景中的完整短句。自动转写只作为候选文字与时间依据，结合画面动作核对角色；无法验证的字段明确留为未验证，不编造听辨。
2. 使用已缓存的 Seed-VC 作者源码快照 `51383efd921027683c89e5348211d93ff12ac2a8`，普通语音 `f0_condition = false`。仅在独立忽略目录准备必要依赖和固定版本权重，校验公开 LFS SHA-256，不修改已有模型环境或作者源码。下载一轮限时 480 秒，网络分块最多一次重试，保留有效已下载块；三轮没有实质进展就停止报告。
3. 若原参考有配乐，复用已有分离器做工作副本。使用所选短句与原已通过纯唱声做一次 CPU 语音转换，固定 25 步、CFG 0.7、长度 1.0、无变调，生成最多一次；若入口错误，依据实际报错修正适配，不换种子试音色。
4. 将生成对白、原已通过完整带伴奏唱段、同一句生成对白组成短对照，段间 500 ms 静音。对白重复用于前后对比，不伪装成连续剧情。验证输入/输出哈希、完整解码、有限值、无 PCM 削波、原唱段逐采样不变；自然度和音色匹配保持待用户听验。

制作入口、参考、模型和证据仅在 `builds/baisuzhen-speech-song-comparison/seed-vc-speech/` 与已有 `baisheying-reference/`，记录更新本计划与本轮音频文档。无游戏集成、扩展角色或正式素材替换。继续直接执行，不使用子智能体。

## 参考原词通过后的两句游戏对白

用户已确认第二版“自然、无电音，音色也一致”。冻结第二版结果作为对白音色与自然度基准，并保留第一版判退。沿用已确定的两句台词“青妹，你看，柳色映着湖波，果然是好风光。”和“君子，雨住了。这伞，奉还。”，不扩展角色或接入游戏。
