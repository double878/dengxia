# 第二幕补救接入

用户要求将第一关补救加到第二幕，沿用已确认的真实动作等待和不制作唱腔边界。

1. 复用 `RemedySystem` 的 8 秒真实时间窗口、事件和失误保留；增加按已完成实际动作结算的入口，不伪造整关评分。
2. 第二幕动作提示出现后准备 8 秒，仍未完成则开启一次补救；取杯和递杯独立。正常离场、饮酒、暗场换蛇、显形与返回均可补救；误退场提示原角色恢复。
3. 复用第一关示范手绘制及既有慢锣鼓；琥珀框、轻压幕布、行动方向和目标标记帮助玩家操作。灯反馈恢复不补回灯油。菜单暂停冻结所有补救显示与计时。
4. 超时只结束提示、不替演、不跳剧情，同一步不反复开窗；后续动作仍能完成。对白与普通自由身段不额外判错。
5. 先观察正式宿主缺补救的失败测试，再实现、解析、定向测试及 Windows 可见检查。收尾执行第一关相关回归、三项门禁与导出启动；接回原工程、提交推送并更新已有 PR。

范围：第二关第二场厅堂。第二关第一场、整关评分/录放与第三幕不新增行为。
