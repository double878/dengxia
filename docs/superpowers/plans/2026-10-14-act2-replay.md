# 第二关观看选择、完整回放和下一关入口

用户已指定沿用第一关流程；直接在现有干净 worktree 顺序执行，不使用子智能体。

目标：第二场许仙惊倒收势后，观众选择看或不看整关真实幕前回放；不看、跳过、自然结束都到收场，下一次鼠标点击进入第三关《盗仙草》开场。第三关正式操演尚未制作，本轮只接入口。

1. 先添加正式流程回归，确认现状因未录制/未完成衔接而失败。
2. 两场共用一份 CPerformanceRecord，各宿主固定步末读取唯一 MusicClock；场间时间连续。记录人物、灯、坐倒、入口遮挡、杯、分节蛇、字幕、暗场及音源读数和事件；菜单暂停不采，等待和补救完整采。
3. 复用 CReplayPlayer/CResultFlow/PerformanceReplay。按记录切换布景、演员和声音，只读记录、不运行剧情判定。跨场与跳段不预插值；支持暂停、继续、跳过。
4. 第二场末尾保留倒地与重音尾声，再发一次完成信号。复用观看选择页和收场页，防止按钮点击透传下一关。接第三关开场页，避免错误加载第一关或旧教学第三关。
5. 先解析检查，再定向流程、动作、补救、第一关录放回归；Windows 图形/实际音频回归。依 TECH_DESIGN 执行 import、startup、Windows export 三项门禁并启动发布包。
6. 检查 diff 和临时产物，更新录放契约与交付记录，提交/push 现有分支并更新 PR16。只整合本轮 delta 回原工程，保留无关改动。

验收：两场一条记录，采样点逐字段一致；真实时间包含等待和收势，排除菜单暂停；回放正确恢复法海与白素贞身份、坐姿、杯、蛇、灯、倒地、对白、对唱、出场音乐与落地重音；四种收场路径正确且不能重复进入下一关。
