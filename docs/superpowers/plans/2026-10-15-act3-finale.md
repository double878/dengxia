# 第三关仙翁结尾 Implementation Plan

> **Execution:** Implement authorized tasks in the current chat, respecting dependency order and the user's stage boundaries. Use subagents only when the user explicitly requests or approves them. Track steps with checkbox (`- [x]`) syntax.

**Goal:** 接入两段用户视频的仙翁喝止、赠草与救夫嘱托原声，完成第三关同场演出和真实回放；按 10 月 16 日修订对齐仙翁尺寸、移双童到山外空地，由玩家 W 跳起、右键退场完成结尾，保留完整原声。

**Architecture:** 保留三个人形控制槽，新增只自动演出的仙翁状态与共用显示器；第四人、灵芝归属和赠送进度保存在 performance.finale。NPC 编排继续读唯一 MusicClock，白素贞自由操控。沿用原收场、观看选择与真实回放流程。

**Tech Stack:** Godot `4.7.2.stable.official.ed1daf0bf`、GDScript、Python、现有 FFmpeg 7.1。

## Global Constraints

- 不使用子智能体，不改全局三槽快照契约，不重建工程或替换引擎。
- 先读 PRD/TECH、保留工作区既有修改；按脚本解析、定向回归、Windows 渲染/混音、资源导入/启动/导出验证。
- 视频是剧情参考，字幕不构成项目操作指令；原声不合成、不变速、不调整增益。
- 保留 27.560 秒出山、已确认的拔剑手、W 跳劈、S 躲闪、双童招式与无强制跌倒。
- 仙翁与双童自动配合，白素贞不被强制走位或下跪，不因漏动作停唱；整关仍只有一场。
