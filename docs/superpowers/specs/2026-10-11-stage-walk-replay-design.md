# 正式演出布景、步态与可选回放

用户已确认 1A / 2A / 3A。第一幕白素贞、小青开场在桥面，白素贞沿桥面上下桥，在岸边接还许仙的伞。横向拖动触发交替小步及轻微起伏，停止收脚，双手仍由玩家控制。演出结束先询问“观看幕前回放 / 不看回放”，不看、播完、跳过都进入本幕收场，可再演或观看保留的记录。

复用队友 1739111 的 CStageBinding、CSceneryView、CRainOverlay，以及现有 CPerformanceRecord、CSnapshot、CReplayPlayer、CResultFlow。不合并整个队友分支。桥面取贴图的行走轮廓，映射沿用布景定义的锚点及比例。地形只影响第一幕接地点，不修改手部操作或合拍规则。

录制在唯一 Harness 固定步结束处读状态，不另推进 Runtime、不抢走原始事件。时间轴采用 MusicClock 的真实演出时间（菜单暂停不计），额外保存歌曲位置、音频状态、伞的归属及交接进度。歌曲等待、补救和前向跳段均保持原始长度及顺序。回放只读记录，不重新执行剧情或评分。

幕前仅呈现镜像后的幕布、影人、道具及同一布景；没有幕后签、手、实时正面预览。回放音频复用正式音源，遵循录下的歌曲位置、等待辅轨及收锣事件。暂停冻结音画，继续不会重播收锣；再演释放旧记录。

验收：正式 game_flow 入口显示桥与柳树；两人脚落在桥面；下桥/上桥连续；迈步、停止、手角不受干扰；完成演出不自动播放；完整录制真实等待与跳段；不看/重看/暂停/继续/跳过/再演全部可用。执行定向回归、既有回归、三项 Godot 门禁及 Windows 图形验证。用户已有的 _xiaoqing_slice_tmp 文件保持原样。
