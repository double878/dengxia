## 目标与验收

从第一场自动换入厅堂后，白素贞和许仙对坐，小青在白素贞后侧服侍。短字幕自动推进普通对白，关键剧情等待玩家实际操演；直到许仙取药返回、见到白蛇惊退仰倒，保持惊死定格。

1. 开场三人真实显示并可按空格循环接手，保留拖手、点头、前倾和 R。
2. 坐姿贴合现有凳子；拖离凳子自动起身。只拖手或头不改变坐姿。
3. 许仙取桌上的已盛酒杯，伸手交给白素贞；交接与饮酒读取真实腕点、嘴部位置。未完成不推进，不超时代演。
4. 白素贞说「小青，你就去吧」后，小青答「好吧」；应答结束才开放走到台边并退场。小青离场后，许仙与白素贞先完整对唱，结束前不允许取杯、递杯或饮酒。许仙取药也必须走到台边退场，再从同侧返回。误退场保留位置、姿态与杯归属。
5. 白素贞饮酒后，玩家用 Alt 拖躯干实际弯腰，才触发「官人……我身子有些不适」普通对白；许仙随后以普通对白说去取药。饮前旧姿态、另一演员、等待超时和补救均不能代替饮后弯腰。
6. 许仙取药离场后，玩家压暗灯、收白素贞、上完整白蛇、调灯显形。人身和蛇身互斥，蛇身上场前必须完成饮酒与取药离场。
7. 白蛇按根目录用户参考图制作分节，去背景、花枝及截图界面，保留白色鳞纹、头颈和盘曲造型；整理遮挡和边缘。拖蛇头带动颈及相邻身体弯曲，拖躯干移动整条蛇，松手保持。
8. 许仙从取药一侧返回、走近显形白蛇后自动惊退、仰倒并静止。不得在许仙离场时提前惊倒。
9. 暂停、失焦、换人和退出终止拖动，暂停冻结字幕、饮酒保持和惊倒。
10. 正式入口、第一场换景、第一关操控及录放保持正常；完成 Windows 图形操演和导出验证。

## 用户决定

Q1 A：关键动作手动，普通身段自由。Q2 A：短字幕，无新音频。Q3 A：玩家压灯换蛇。Q4 B：使用工程内参考图。Q5 A：上半身任务已结束，可复用现有改动。Q6 B：分节白蛇。Q7 A：拖离凳子自动站起。Q8 以本轮修订为准：饮后必须实际弯腰再说不适。Q9 A：走到台边再退场。Q10 A：拖头带动相邻节、拖躯干整移。Q11 A：普通对白自动，关键动作等待。饮前对唱占位已由用户选择「先用临时对唱字幕演练」。

## 剧情与推进

开场许仙劝酒 → 小青劝阻 → 许仙提出单独聊聊、请小青多买酒菜 → 白素贞应允 → 小青答「好吧」 → 等小青离场 → 许仙与白素贞对唱 → 等取杯递杯 → 等白素贞饮酒 → 等白素贞实际弯腰 → 白素贞普通对白说不适 → 许仙普通对白说去取药 → 等许仙离场 → 等压暗灯 → 等收白素贞 → 等完整白蛇上场 → 等调亮显形 → 等许仙返回并走近 → 自动惊退仰倒 → 惊死定格。

对白为动作阶段的临时短字幕，后续音频可替换其时标，不伪造当前音频验收。未完成实际动作持续等待。酒杯一处归属，桌面显示随持杯状态消隐，杯随实际手腕。取药用许仙离返表现。

对唱暂以两人各两句、每句 4.5 秒的占位字幕排练，显式标注「临时对唱」；这不是正式唱词、唱腔音源或实测时标。正式音频制作后再替换。饮后弯腰读取白素贞实际 `torso_lean`，达到 20°即可；若饮前已弯到该角度，先扶正到 10°以下（可按 R），再做饮后弯腰。无额外保持时长。弯腰也沿用 8 秒准备、8 秒补救，师父示范实际 Alt 操作，不自动弯腰。

## 模块和技术边界

- 保持 Godot 4.7.2 Standard（4.7.2.stable.official.ed1daf0bf）、同版本导出模板，无第三方运行依赖。
- `act2_hall.gd` 为正式宿主，复用 PuppetController、InputReader、LampController、MusicClock、StageSurface、CStageBinding(stage_id=22) 和 OperatorHand。
- 第二幕动作调度独立放在 `act2_hall_actions.gd`：字幕阶段、实际动作门槛、杯归属、正式离返、换蛇许可和惊倒进度。唯一时钟；等待冻结歌曲时间，真实时间供火光和实际动作保持，菜单暂停冻结两者。
- 人形视图仅新增默认关闭的坐姿与倒地显示参数，共用实体/投影变换及命中几何，不改变第一关默认姿态。
- 白蛇状态、有限分节解算、绘制单独放在 `snake_pose.gd` / `snake_view.gd`；实体和透射视图消费同一状态。分节长度保持、目标限制、关节范围有限，禁止跳变或反折。
- 酒杯从厅堂静态布景转为动态同源道具，场景可隐藏该杯；其他关卡布景默认不受影响。
- `1/2/3` 对应白素贞/许仙/小青，`4` 为完整白蛇；空格循环接手当前在场者。剧情正常下场和误下场分开处理。正常离返不重置其他人的状态。
- 本轮验收人物动作与幕后演出，第二关整关录放、评分及第三幕仍按后续独立切片接入；不把脚本通过描述成这些功能已交付。
