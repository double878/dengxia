# 人形影人上半身操控设计

日期：2026-10-13。状态：用户已确认整体设计，三项实现切片及隔离工程验证完成；原工程接入验证见交付记录。

## 目标和范围

参考用户提供的 15 秒演示视频，让玩家直接拖动手的位置，肩、肘自动配合；增加独立点头、低头、仰头和腰部前倾。下半身的移动、地面路径、迈步、蹲站与快速翻面沿用当前行为。

所有人形角色共用这套操作，包括白素贞、许仙、小青、法海；后续人形角色复用同一接口。完整白蛇属于非人形替身，不套用双臂控制。已接入的录放同步新增姿态字段；第二关未来的整关录放也消费同一状态。本功能不新增第二关饮酒、变蛇、惊倒或第三关剧情。

视频作为动作参考。视频中的编辑界面、文字、选框及工具按钮不是游戏需求。

## 操作契约

| 输入 | 行为 |
| --- | --- |
| 左键拖当前受控影人的手 | 改变该手的位置，固定长度的上臂和前臂自动配合；另一只手保留姿势。 |
| 左键拖头 | 绕颈部枢轴调整低头或仰头，保持身体位置。 |
| Alt+左键拖躯干 | 绕腰部枢轴调整前倾；头、肩、双臂及躯干饰件一起跟随。 |
| 普通左键拖胸签或现有手边移动热区 | 继续控制移动、蹲站和沿移动方向快速翻面。 |
| A / D、Shift+A / Shift+D | 分别上移或下移对应手的目标位置，肩肘自动配合；左右手身份沿用现有定义。 |
| W / S | 两只手的目标位置同时上移或下移。 |
| R | 一次恢复当前影人的上半身自然姿态；双臂垂下、头与腰归正。 |

键盘快捷操作仍有可停住的边界。原第一关的打伞位保留为快捷上举的停靠目标，鼠标拖手按共用关节范围活动；剧情按实际动作到位判定。

一只鼠标一次拖一个部位。鼠标拖某只手时，该手以鼠标为准，键盘仍可操作另一只手；鼠标拖胸签时，键盘可同时抬落双手。同一只手的相反键盘指令互相抵消。

开始拖动时保留抓取偏移，避免手突然跳到鼠标中心。拖动期间锁定抓住的部位，经过头、躯干或另一只手不改换目标。Alt 躯干拖动优先于胸签移动；普通命中优先识别手、头，再识别胸签。只命中当前受控实体的可见部位，灯影不作为拖动目标，首次出场被布景遮住的部位不能抓取。

松开鼠标或快捷键后保持最后姿态。换人、挂起、误退场再上场保留该人的姿态，输入瞬态结束，旧拖动不传给新接手者。暂停、失去焦点、场景退出结束拖动并保留已生效动作；恢复时必须重新抓取。R 先结束当前拖动再复位，防止下一次鼠标移动立即覆盖复位结果。

恢复上半身不改变位置、面向、翻面进度、蹲站、步态、角色身份、头部归属、挂钩和道具归属。持伞时复位只让伞随手移动，不代替接伞或还伞。

## 姿态与关节

复用现有分件、长度和枢轴。腰部转动固定在现有髋部锚点，头部转动固定在颈部；弯腰本身不推进步态或改变蹲站。分件连接处保留皮革重叠，避免抬手、弯肘、弯腰时露出断口。

双臂仅需要固定两段的平面几何计算，不引入通用骨骼系统、网格蒙皮或第三方依赖。超过可达范围时把目标约束到可达边界，手臂长度不变。靠近肩点、完全伸直、经过身体附近时，弯肘方向保持连续，避免肘突然翻到另一侧。非法或非有限输入保留上一合法姿态并报告上下文。

初始可调范围建议为：肩部沿用 -90°～180°，肘部屈曲 0°～150°，头部俯仰约 ±30°，腰部前倾 0°～45°。这些是实现起点，不是从视频测得的角度；以 Windows 图形试玩的连贯性、衣饰连接及动作可达性校准。角色面向决定前倾方向，头部不增加独立左右翻面。

运行状态保留现有手角作为肩角，新增左右肘角、头部俯仰角和腰部前倾角。显示、输入命中、道具挂点和动作到位判断共用姿态几何；渲染端保持只读，不反过来写入操控状态。鼠标目标属于输入瞬态，记录以实际关节姿态为准。

旧数据缺少新增字段时按肘角为零、头腰归正读取，以重建原来的直臂姿态。当前演出和回放分别持有自己的状态，不共用可写实例。

## 道具与现有流程

持伞、持杖和三根竹签读取新的实际挂点。保留现有朝向规则：伞面朝上，锡杖保持竖直；手掌随前臂方向，道具归属和真实交接继续由原模块管理。躯干饰带随前倾转动。

现有接伞手高及抬手到位判断依赖直臂公式，必须迁移到共享几何读数。保留现有交接窗口、拍点与剧情目标，验证正常借伞、还伞和故意不到位两条路径；不能只修改画面而让判定继续按旧角度估算。

灯距、显露度、上场、换人、退场、暂停及各关已有规则沿用当前契约。演出仍在幕后，幕前只在回放中展示。

## 辅助标记与回放

当前受控影人允许悬停提示：手和头显示小标记，躯干提示 Alt；拖动时仅突出正在控制的部位。提示使用可操作部位，不展示视频中的编辑选框和整套骨架。回放不显示操控提示，其他未受控影人不显示可拖动标记。

沿用唯一 MusicClock 与 30 Hz 实际姿态快照。新增肩肘、头和腰状态进入序列化、快照校验、变化检测、插值、回放应用及回放核对。恢复姿态等瞬时变化立即记录，避免两次采样之间丢失；幕前读取实际记录，不重新执行拖手求解或剧情判定。

第二关当前尚无整关录放，本功能仅让新姿态契约可被相同记录链路消费，不能将其表述为已经交付第二关完整录放。
